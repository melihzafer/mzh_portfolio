✨ Features
Your portfolio already has an amazing feature set. Let's list them clearly!

🦸‍♂️ Hero Typewriter Effect: Cycles through your roles with an optional glitch animation.

🧲 Magnetic CTAs: Interactive buttons that follow the cursor with smooth spring animations.

🃏 3D Tilt Cards: Project cards with a cool 3D perspective transform on hover.

💻 Code Editor "About" Page: A unique VS Code-inspired layout with tabs and line numbers.

📊 Animated Skill Bars: Progress bars that animate into view when scrolled to.

⌨️ Command Palette: ⌘K navigation for quick access to all pages and actions.

♿ Accessibility: Full keyboard navigation, prefers-reduced-motion support, and semantic ARIA labels.

📱 Mobile Optimized: Fully responsive, touch-friendly, and a great mobile UX.

🛠️ Tech Stack
Framework: Next.js 15 (App Router)

Language: TypeScript

Styling: TailwindCSS 4 + SCSS Modules

Animation: Framer Motion 12

UI: Custom shadcn/ui components

Icons: Lucide React

Content: MDX for case studies

Forms: React Hook Form + Zod for validation

Deployment: Netlify

🏃‍♂️ Quick Start
Prerequisites
Node.js 20+

npm / pnpm / yarn

Installation
Bash

# Clone the repository
git clone https://github.com/melihzafer/mzh_portfolio.git

# Navigate to the project directory
cd mzh_portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
Visit http://localhost:3000 in your browser to see the portfolio.
